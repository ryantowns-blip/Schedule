# v0.6.0 Settings & Customization

This version builds on v0.5.4 and adds:

- Settings screen accessible from the home AppBar.
- Persistent color customization for regular shifts, overtime, off/annual leave, sick leave, and holiday leave.
- Reset-to-default color settings.
- Clearer `Schedule data last updated` date/time label tied to the last successful WMT refresh.
- Existing TODAY highlight retained.
- Annual leave displayed as Off and holiday leave displayed as HL.
- More robust WMT extraction for WebView HTML that serializes annual leave as `A&lt;...&gt;`.

Previous versions remain preserved in versioned branches/files for regression and rollback.
