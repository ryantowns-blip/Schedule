# v0.12.1 — Manual leave usage

- Adds dated manual leave usage for unscheduled absences not visible in schedule screenshots.
- Supports Annual Leave and Sick Leave with decimal hour amounts.
- Allows manual entries to be edited or deleted.
- Includes manual hours in current leave-year projections and warnings.
- Keeps manual transactions separate from automatically imported schedule and approved-leave records.
- Shows compact current and projected Annual and Sick balances on the home screen while retaining the full Leave Balance page.
