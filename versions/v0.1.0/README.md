# ATC Schedule Manager v0.1.0

Initial tracked development snapshot.

## Included
- Flutter starter app
- WMT shift parsing foundation
- Support for normal, overtime, day-off, L/Q/S/C modifiers
- Xtra before/after/split overtime logic
- Parser tests
- GitHub Actions Android APK build workflow

## Versioning policy
Each meaningful milestone will receive its own folder under `versions/` with release notes, a version name, and the commit/build reference used for that snapshot.

Active development remains in the repository root so we do not duplicate the entire source tree for every version. Git history remains the authoritative source for exact code snapshots.
